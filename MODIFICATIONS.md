# Tally Android modifications

## Expense reminder calls
- Replaces the one-shot evening nudge with a repeating, full-screen expense reminder.
- Configure start time, stop time, and repeat interval (15, 30, or 60 minutes).
- Green **Already added** confirms today's expenses are recorded and stops reminders for the day.
- Red **Not yet** declines and schedules the next prompt within the configured window.
- Android 14+ full-screen-intent access is included in the reminder permissions card.
- Existing balance checks, loan reminders, and backup reminders remain in place.

## Home-screen widget
- Adds direct expense, income, and transfer shortcuts.
- Each shortcut opens the matching entry form directly, without the Quick Add chooser.
- The original balance/spending content and launcher icon remain.
